# Website interaction design

The page uses the accepted deck as its content source and explains each subject in the context of the passenger and airline decisions it supports.

| Earlier treatment | Current treatment | Reason |
| --- | --- | --- |
| A separate technology page | Inline service tabs and an expandable matching example | Keeps the complete explanation in one reading sequence |
| Passenger name over the person icon | Seat number, icon and name in separate flex rows | Preserves legibility at narrow widths |
| Earlier 400-credit seat reward | 160-credit reward with a 600-credit starting balance | Matches the current example catalogue |
| Dense detail presented together | Resource and interface tabs | Lets readers inspect one resource or task at a time |
| General control assurances | Marketplace differentiation and concrete operating value | Explains why the service matters |

The story does not advance automatically. Each action follows an authored example, and reduced-motion or keyboard interaction skips entrance motion. Tab groups use roving focus and support arrow keys, Home and End. The matching example runs the exported domain engine only when opened.
